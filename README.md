# 💰 WhereMyMoney («Где мои деньги»)

Современное, быстрое и тактильное мобильное приложение для персонального финансового учета. Создано по философии **Local-First**: мгновенный отклик, работа без интернета, приватность ваших данных и готовность к будущей облачной синхронизации.

---

## 🎯 Миссия и идея

Большинство трекеров расходов забрасывают через две недели из-за муторного ввода.  
В **WhereMyMoney** фокус сделан на:
1. **Скорость записи (< 3 секунд)**: открыл $\rightarrow$ набрал сумму $\rightarrow$ нажал категорию $\rightarrow$ сохранено.
2. **Премиальный fintech-дизайн (Anti-Slop)**: глубокая темная палитра Obsidian/Slate, изумрудные и коралловые акценты, плавная анимация и никакой серости.
3. **Честный Local-First**: база данных SQLite прямо на вашем телефоне. Никаких обязательных регистраций на старте.

---

## 🛠 Технологический стек

* **Фреймворк**: [Flutter](https://flutter.dev/) (версия 3.x, Dart 3.13+ null-safety).
* **Целевая платформа**: Android (с поддержкой кроссплатформенного запуска на Windows/iOS).
* **Локальная база данных**: `sqflite` + `sqflite_common_ffi` (чистый, быстрый SQLite без долгой кодогенерации).
* **Стейт-менеджмент**: `Provider` (предсказуемый, расширяемый реактивный слой).
* **Сканирование QR чеков**: `mobile_scanner` (быстрое нативное считывание QR-кодов с камеры устройства).
* **Графика и чарты**: `fl_chart` (высокопроизводительные интерактивные круговые и линейные диаграммы).
* **Форматирование и утилиты**: `intl`, `uuid`, `path_provider`.

## 🚀 Запуск и сборка

### Требования
* Flutter SDK $\ge$ 3.13
* Android SDK (для запуска на телефоне/эмуляторе) или C++ Build Tools (для Windows)

### Запуск в режиме разработки
```bash
# Получить зависимости
flutter pub get

# Быстрый запуск для разработки на Windows:
flutter run -d windows

# Запуск на подключенном Android телефоне:
flutter run -d <android-device-id>
```

### Проверка качества кода
```bash
flutter analyze
```
